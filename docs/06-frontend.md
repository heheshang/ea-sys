# 前端界面设计（Vue 3 + TypeScript + Element Plus）

## 1. 技术选型

| 项 | 选型 | 说明 |
|---|---|---|
| 框架 | Vue 3 + TypeScript + Vite | 用户指定 |
| DAG 画布 | @vue-flow/core（Vue Flow）| xyflow 官方 Vue 移植（与 React Flow 同 API 家族）；配套 @vue-flow/minimap、@vue-flow/controls、@vue-flow/node-resizer |
| 状态管理 | Pinia（画布本地态）+ @tanstack/vue-query（服务端数据）| 画布交互高频本地化，服务数据缓存化 |
| UI 组件库 | Element Plus | 用户指定 |
| 图表 | ECharts + vue-echarts | 留存曲线、漏斗、渠道效果 |
| 路由/权限 | vue-router + 路由守卫 + 按钮级权限指令（对接 RBAC）| 运营 / 审核员 / 管理员 |
| 自动布局 | dagre（@dagrejs/dagre）| 工作流导入自动排布 |

## 3. 页面明细

### 3.1 工作流列表
- 表格：名称、状态（草稿/已发布/已归档）、版本、最近执行结果（成功/失败/运行中）、更新时间
- 操作：编辑、发布、复制、归档；搜索 + 状态筛选

### 3.2 DAG 编排画布（核心页面，三栏布局）
- **左栏 · 节点面板**：可拖拽节点类型 —— 触发 / 条件 / 智能体分流 / 延迟 / 动作 / 更新 / 结束
- **中栏 · 画布**：
  - 节点外观按类型区分（触发=菱形、条件=圆角矩形、动作=彩条图标等）
  - 连线即条件边：默认 `true`，可点击编辑出边条件
  - 节点角标显示配置缺失/校验错误；环路与无出口拓扑校验实时提示
  - 自动布局（dagre）兜底乱序导入
- **右栏 · 配置面板**：选中节点/边的动态表单，按类型切换：
  - 触发：`triggerType` 三态 —— 定时（Cron 表达式 + 时区选择）/ 事件（事件名 + 过滤条件）/ 手动 / API（展示调用说明）
  - 条件/出边条件：规则构建器（AND/OR 组合的字段-操作符-值 表单）
  - 智能体分流：分层维度选择、模型档位、置信度阈值、fallback 策略选择
  - 延迟：相对时长（天/时/分）或固定时刻
  - 动作：通道 + 模板选择，变量预览
- **顶栏**：保存草稿 / 导入计划校验 / 干跑预览 / 发布 / 版本历史

### 3.3 发布与干跑
- 发布弹窗触发干跑 → 展示报告：各节点预计触达人数、预计成本、分层分布
- 确认后发布新版本；已发布版本不可改，改动自动转草稿
- 版本历史支持对比（已发布 vs 草稿 diff 高亮）与回滚

### 3.4 人群管理
- 人群列表 + 圈选规则构建器（属性 / 标签 / 行为事件组合）
- 人群详情：成员预览（分页）、快照列表、关联工作流
- 同步圈选进度展示（大人群异步 building → ready）

### 3.5 触达监控
- 执行实例列表：触发类型、人群快照、状态、耗时、成功率、成本合计
- **执行详情（只读画布回放）**：节点按执行状态着色（done/failed/skipped/running），点节点看统计（该节点触达人数/失败数/平均耗时）与失败明细
- 触达明细表：用户（脱敏）、通道、模板、状态、回执、成本；可按执行/节点/通道筛选
- 实时监控：队列积压、限流触发告警、通道失败率

### 3.6 智能体配置
- 分层策略列表：已发布策略、版本、回滚按钮（人工审核闸门入口）
- 路由规则配置：可视化编辑确定性 fallback（通道优先级、已触达后置等）
- 全局参数：模型档位映射、置信度阈值、每租户 LLM 调用配额
- 决策审计日志：按 Agent / 时间 / 租户筛选，可展开查看入参摘要与输出（脱敏）

### 3.7 模板与通道
- 消息模板：按通道管理，FreeMarker 变量声明 + 实景预览（手机/邮件客户端样式）
- 通道配置：短信签名、SMTP、推送证书；每通道「测试发送」按钮
- 频率控制：租户每日上限、静默期、触达时间窗

### 3.8 留存看板（M5）
- 留存曲线（区间留存）、转化漏斗、渠道效果（送达率/转化率）
- 工作流效果：每个工作流对留存/复购的影响对比
- AB 与灰度结果对比（后续扩展）

### 3.9 管理（SaaS）
- 租户管理（超管）：租户列表、配额调整、启用/停用
- 成员与权限：角色（运营 / 审核员 / 管理员），按钮级权限点

### 3.10 计划导入与校验（发布前置）
- 工作流编辑页顶栏「导入计划校验」→ 上传弹窗：拖拽上传，支持 xlsx / csv / docx / pdf / md / txt，≤10MB，类型白名单；弹窗内提供「下载模板」（xlsx / csv，见 `docs/07-plan-template.md`）
- 进度态：上传 → 解析中 → 校验中（SSE / 轮询），展示当前阶段；失败时提示原因
- 校验报告视图：分级清单（BLOCKED 冲突 / 警告 / 通过），每条含「计划要求 / 工作流现状 / 差异说明 / 修正建议」
- 「一键应用建议」：差异建议生成工作流草稿修改，进入画布人工确认后保存（不直接改已发布版本）
- `decision=BLOCKED` 时发布按钮置灰并展示原因；强制发布走审批流程
- 历史报告：工作流下校验记录列表，可回看

## 4. DAG 画布关键交互

| 交互 | 设计 |
|---|---|
| 新建节点 | 左栏拖入画布，自动接线到选中节点 |
| 连线 | 拖拽出边；条件边点击编辑条件表达式，普通边显示为默认 `true` |
| 节点配置 | 选中 → 右侧动态表单，配置缺失时节点角标红点 + 发布前校验清单 |
| 环路检测 | 保存/发布时拓扑校验：环路、多触发、无出口、孤儿节点 |
| 干跑 | 发布弹窗内触发，报告卡片展示预计人数/成本，确认才发布 |
| 执行回放 | 从监控进入只读画布，按 `execution_node_state` 着色并展示节点统计 |
| 导入计划 | 上传文件 → 解析进度 → 分级校验报告（冲突/警告/通过），冲突项展示差异与建议 |
| 一键应用 | 报告建议一键生成工作流草稿修改，进入画布人工确认后保存 |

## 5. 与后端的 API 契约

| 接口 | 说明 |
|---|---|
| `GET/POST/PUT /api/workflows` `POST /api/workflows/{id}/publish` | 工作流 CRUD 与发布（发布前干跑）|
| `POST /api/workflows/{id}/dry-run` | 干跑报告 |
| `GET /api/audiences` `POST /api/audiences/{id}/snapshot` | 人群与快照 |
| `GET /api/executions` `GET /api/executions/{id}` | 执行实例与节点状态 |
| `GET /api/deliveries` | 触达明细（分页 + 筛选）|
| `GET/PUT /api/agent/strategy` `GET /api/agent/audit-logs` | 分层策略与决策审计 |
| `GET/PUT /api/templates` `GET/PUT /api/channels` | 模板与通道配置 |
| `GET /api/dashboard/*` | 看板聚合（M5）|
| `POST /api/workflows/{id}/validate-plan` | 上传计划文件（multipart），异步返回校验报告 |
| `GET /api/workflows/{id}/validation-reports` | 历史校验报告列表 |

统一约定：`X-Tenant-Id` 租户头 + JWT；列表接口统一分页；长任务（圈选、干跑）走任务轮询或 SSE 进度。
