# 运营计划模板（Excel v1）

「计划导入校验」的输入格式。首版固定模板（运营照表填写）→ M4 后支持自由格式文件。支持 `.xlsx` / `.csv`（同结构）。

## 工作簿结构 —— 4 个 Sheet

### Sheet 1「计划概览」

| 列 | 必填 | 说明 | 示例 |
|---|---|---|---|
| 计划名称 | 是 | 计划标识 | 7天未复购促活 |
| 目标人群 | 是 | 人群描述（语义比对对象）| 近30天活跃、7天未复购、价值中高 |
| 触发方式 | 是 | TIMED（定时）/ EVENT（立即·事件）/ MANUAL（立即·手动）| TIMED |
| 触发时间 | 条件必填 | TIMED 时必填：Cron 或 `yyyy-MM-dd HH:mm` | `0 0 9 * * 1` |
| 事件名 | 条件必填 | EVENT 时必填 | ORDER_PAID |
| 时区 | 否 | 默认租户时区 | Asia/Shanghai |
| 预算上限 | 否 | 每日成本预算（元）| 500 |

### Sheet 2「触达计划」（核心路由表）

| 列 | 必填 | 说明 |
|---|---|---|
| 人群分层 | 是 | 通道优先分层：全部 / 双通道 / 仅手机 / 仅邮箱；分层 Agent 可扩展为新层 |
| 通道 | 是 | sms / email / push（微信接入后允许 wechat）|
| 顺序 | 是 | 1, 2, 3… 决定 DAG 动作先后 |
| 时刻/延迟 | 是 | `D+0 09:00` / `D+1` / 固定时刻 |
| 消息模板 | 是 | 引用 `message_template.name`，校验时检查存在性 |
| 单用户频率上限 | 否 | 每用户每日触达上限（比对租户配额与静默期）|
| 备注 | 否 | |

示例行：

| 人群分层 | 通道 | 顺序 | 时刻/延迟 | 消息模板 | 单用户频率上限 |
|---|---|---|---|---|---|
| 双通道 | sms | 1 | D+0 09:00 | 复购提醒-短信 | 1 |
| 双通道 | email | 2 | D+1 10:00 | 复购提醒-邮件 | 1 |
| 仅手机 | sms | 1 | D+0 09:00 | 复购提醒-短信 | 1 |
| 仅邮箱 | email | 1 | D+0 09:00 | 复购提醒-邮件 | 1 |

### Sheet 3「人群规则」（可选）

| 列 | 说明 |
|---|---|
| 操作 | AND / OR，多行组合 |
| 字段 | `contact.*`、`event.*`、`history.*`（与工作流条件 DSL 同字段体系）|
| 操作符 | equals / in / gt / gte / lt / lte / contains |
| 值 | 单值或多值（逗号分隔）|

空 Sheet 视为「沿用工作流既有圈选人群」。示例：

| 操作 | 字段 | 操作符 | 值 |
|---|---|---|---|
| AND | contact.value_tier | in | high,mid |
| AND | contact.last_purchase_days | gt | 7 |

### Sheet 4「文案要求」（可选）

| 列 | 说明 | 示例 |
|---|---|---|
| 通道 | sms / email | sms |
| 模板 | 对应 Sheet 2 模板名 | 复购提醒-短信 |
| 要求 | 文案约束（语义比对 + 合规提示）| 变量齐全、不含营销违禁词 |

## 解析与校验映射

| 模板位置 | → 结构化计划字段 | → 校验维度（计划校验 Agent）|
|---|---|---|
| Sheet1 触发方式/时间/事件 | `trigger` | 触发（确定性）|
| Sheet2 人群分层 | `audience.layers` | 分层与人群定义（语义）|
| Sheet2 通道 | `channels` | 通道启用状态（确定性）|
| Sheet2 顺序 | `route_order` | 路由顺序 vs DAG 出边（确定性）|
| Sheet2 时刻/延迟 | `timing` | 时序/延迟节点（确定性）|
| Sheet2 频率上限 | `frequency` | 配额与静默期（确定性）→ 越限 BLOCKED |
| Sheet3 | `audience.rules` | 人群定义（语义）|
| Sheet4 | `copy_notes` | 文案要求（语义）|

## 边界与容错

- 文件 ≤ 10MB；仅 `.xlsx` / `.csv`；列名不符或必填缺失 → 解析失败并报出行列位置
- 模板内标注版本号（如「模板版本 v1」单元格），解析器按版本兼容处理
- 扫描版 PDF 不支持（OCR 后续）；自由格式文件解析为 M4 增强项
- 解析 Agent 输出仍走 schema 校验 + 置信度 + 审计，见 `docs/04-agent-design.md §9`
